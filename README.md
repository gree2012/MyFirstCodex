# MyFirstCodex

这是一个中文个人网页。页面上方有欢迎语、个人介绍和兴趣爱好，点击「点击我看看」会显示一句问候。页面底部的时钟每秒更新。你也可以用页面中的「我的待办事项」安排任务和查看进度。

## 打开网页

1. 在文件资源管理器中打开 `MyFirstCodex` 文件夹。
2. 双击 [index.html](index.html)，用浏览器打开。如果它在编辑器中打开，可以右键点击文件，选择「打开方式」，再选择浏览器。

网页的内容和功能都在这一个文件里，无需安装项目依赖或启动服务器。

## 使用待办事项

| 功能 | 操作 |
| --- | --- |
| 添加、完成和删除 | 输入任务标题，选择分类，可设置截止日期和重复周期，再点击「添加」。做完后勾选标题前的方框。点击「删除」只移除当前这一条。每条任务都可以点击「编辑」。 |
| 备注 | 点击任务的「编辑」，在弹窗中输入或修改多行备注，再点击「保存」。 |
| 分类 | 可选择工作、学习、生活或未分类。点击任务的「编辑」，在弹窗中修改分类并保存。列表上方的「分类筛选」可查看指定分类或全部任务。 |
| 搜索 | 在搜索框输入标题或已保存备注里的关键词，列表会随输入更新。清空搜索框后，会显示当前分类下的所有任务。 |
| 截止日期与优先级 | 点击任务的「编辑」，在弹窗中修改截止日期和高、中、低优先级并保存。截止日期过后仍未完成的任务会显示红色「已逾期」。 |
| 重复周期 | 添加或编辑时可选择不重复、每天、每周或每月。重复任务必须填写截止日期。「重复周期」筛选可以与搜索、分类、完成状态及排序一起使用。 |
| 排序 | 可按添加顺序、截止日期从早到晚或优先级从高到低排列。按日期排序时，没有截止日期的任务排在最后。排序可以和搜索、分类筛选一起用。 |

编辑窗口可以同时修改标题、截止日期、优先级、备注、分类和重复周期。点击「取消」或按 Esc 不会保存。标题不能为空。

首次完成重复任务时，原任务保留为已完成，并生成一条独立的下一次任务。提前完成仍按原计划续期。逾期完成时，跳到本地当天之后的下一次计划日期。每月任务遇到较短的月份会使用月底，之后恢复原定日期，例如 1 月 31 日、2 月 28 日、3 月 31 日。手动修改每月任务的截止日期时，以新日期的日号作为原定日期。

取消完成会保留已经生成的下一条，再次完成同一条也不会重复生成。要停止续期，请将尚未生成后续任务的那一条改为「不重复」。修改周期只影响当前任务及其以后生成的任务，已经生成的任务可以分别编辑。

顶部的「任务进度统计」显示全部任务的总数、已完成、未完成、逾期和各分类完成情况。完成率用已完成数除以任务总数计算，没有任务时显示 0%。顶部汇总始终包含全部任务。

## 日历视图

页面默认显示列表。点击「日历视图」可以按月查看有截止日期的任务，使用「上个月」「今天」「下个月」导航。每周从星期一开始，今天会高亮。搜索、分类、完成状态和重复周期筛选在两个视图之间共享，日期格显示筛选后的任务数量。

点击日期可查看当天所有符合筛选条件的任务。点击任务标题会打开原有的编辑窗口，保存后任务会显示在新的截止日期上。点击「在这一天新增任务」会在添加表单预填日期，提交前可以修改。完成和删除任务可在列表视图操作。

没有截止日期的任务仍在列表中。日历只显示已经保存的任务，查看未来月份不会提前生成重复任务。

## 统计视图

点击「统计视图」可以查看当前搜索和筛选条件下的任务总数、已完成数、未完成数、完成率，以及分类和优先级分布。每条实际存在的重复任务分别计数。列表、日历和统计视图共享筛选条件。

「完成趋势」可切换最近 7 天、30 天或 6 个月，均包含本地今天或本月。展开「查看完成趋势数据」可逐项查看日期和数量。趋势按实际勾选完成的时间统计。取消完成会清除完成时间，再次完成会记录新的时间。缺少完成时间的旧任务仍计入已完成总数。

## 保存、备份与恢复

任务和排序设置保存在当前浏览器的本地存储里。用同一个浏览器和用户配置重新打开原位置的网页，通常可以继续使用之前的数据。换浏览器、换设备或移动网页文件后，原来的记录可能不会显示。清除浏览器的站点数据也可能删掉任务。

- **导出备份**。点击「导出备份」，浏览器会下载 `待办事项备份.json`。版本 4 包括全部任务、排序设置、重复规则、防重复生成状态，以及已记录的实际完成时间。恢复 v4 备份请使用支持统计视图的版本。
- **导入恢复**。点击「导入备份」，选择此前导出的 JSON 文件。页面会先检查文件，再显示确认弹窗。点击「确认覆盖」后，备份里的任务会替换当前任务。如果两份都想保留，先导出当前任务并另存一份。取消导入或选择无效文件时，当前任务会保留。旧备份缺少备注或分类时，恢复后对应显示为空备注或未分类。

仍可导入版本 1、2 和 3 的备份。没有重复信息的任务按普通任务处理，导入过程不会生成下一条任务，也不会为没有完成时间的历史任务补写时间。已有本地任务会继续读取，无需迁移。

## 多窗口使用

同一个页面在多个窗口打开时，网页会协调写入，并在保存前检查本地数据是否已经变化。看到页面顶部提示「检测到其他窗口已更新，请刷新后再操作」时，本次修改没有保存，其他窗口已保存的任务会保留。

如果保存编辑时发现其他窗口已修改或删除任务，页面会阻止本次写入，并在编辑窗口中保留尚未保存的输入。

1. 先复制当前窗口里还没保存的任务标题或备注。
2. 刷新当前页面，加载最新的待办列表。
3. 检查任务的最新状态，再粘贴文字或重做刚才的修改。

如果浏览器无法协调多窗口写入，页面会暂停保存。读取已保存的数据失败或发现格式异常时，页面也会暂停写入，以保护原始数据。遇到这些提示时，先保留已有的备份文件和浏览器数据。
